# COBOL 85 Verb Reference

This reference is split into logical groups so each COBOL 85 verb is easy to find and study.

## Scope

This set covers the COBOL 85 verbs, including verbs from optional modules (for example, Report Writer and Communication). Some optional verbs are compiler-dependent.

If a verb is accepted by one compiler but not another, keep the example style and adjust syntax to your compiler's manual.
